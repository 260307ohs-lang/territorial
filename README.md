# Territorial Prototype

브라우저에서 바로 하는 영토 확장 전략 게임입니다. HTML 파일 하나로 되어 있어 설치가 필요 없습니다.

**플레이:** https://260307ohs-lang.github.io/territorial/

## 조작
- 좌클릭: 공격 / 확장
- 우클릭: 원형 메뉴 (공격 · 화력 지원 · 외교 · 건설)
- 우클릭 드래그 또는 WASD: 화면 이동, 휠: 확대·축소
- 1~4: 투입 비율, Q/E: 전면·돌파, U: 기갑
- F 참호 · G 도시 · V 철도 · B 수도 이전
- K 폭격 · H 포병 · P 공수 · N 미사일 (시대가 열리면)
- T: 커서 아래 나라와 외교, M: 지도 모드, C: 내 나라로
- F1: 도움말, L: 이벤트 기록, Alt: 비용 내역, ESC: 취소
